Première version de **Ligne EMAK** : votre poste EMAK Telecom sur Zorin OS / Ubuntu.

### Installer
1. Téléchargez `ligne-emak_1.0.0_all.deb` ci-dessous.
2. Double-cliquez dessus, puis **Installer** (ou `sudo apt install ./ligne-emak_1.0.0_all.deb`).
3. Ouvrez **Ligne EMAK** et entrez votre numéro de poste, le mot de passe du poste et le domaine de la compagnie (`acme` pour `acme.emaktalk.com`).

### Inclus
- Appels sortants et entrants (notification avec Répondre / Refuser, sonnerie)
- Muet, attente, transfert, clavier pendant l'appel
- Messagerie vocale (*97) avec compteur de nouveaux messages
- Historique avec appels manqués et rappel en un clic
- Démarrage avec l'ordinateur, reconnexion après veille ou changement de réseau, liens `tel:`
- Mot de passe conservé dans le trousseau de clés

Compatible Zorin OS 17/18 et Ubuntu 22.04/24.04. Projet indépendant, non affilié à EMAK Telecom.
